# Programa CLP com assistência do Antigravity
Este projeto teve como objetivo finalizar um teste no Editor Programa CLP da Branqs Automação utilizando o Antigravity como ferramenta auxiliar.

# Metodologia
O Antigravity transcreveu os materiais de estudos da Branqs com um código Python e usou a transcrição para auditar e testar o meu código CLP que foi feito por mim mesmo anteriormente.

# Linguagens utilizadas
- CLP
- Python

# Ferramentas utilizadas
- Editor Programa CLP Branqs (Para escrita do código CLP e testes)
- Antigravity (Para auditoria e apoio)
